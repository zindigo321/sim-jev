# 第一阶段验收清单

测试驱动 `Simulation` 的真实事件处理路径；只注入确定性任务及初始飞行寿命，不另写仿真器，不用 mock 替代业务逻辑。所有时间均为小时。

| 验收项 | 确定性案例与断言 | 测试位置 |
| --- | --- | --- |
| 1. 无故障完成 | 两架飞机完整执行；成功计一次、价值到账、飞行小时正确 | `test_engine.py` |
| 2. 飞机不足 | 全有或全无派机，未执行任务不占机 | `test_engine.py` |
| 3. 飞行故障 | 整项任务只失败一次、健康飞机释放、坏机进入保障 | `test_engine.py` |
| 4. 过期事件 | 中止任务的结束及故障事件不影响后续任务 | `test_engine.py` |
| 5. 飞行暴露 | 地面不耗寿命；中止后仅计实际飞行；修复前寿命不重置 | `test_engine.py` |
| 6. 机位排队 | 有件无位，按请求时间及 ID 排队；完工后接续维修 | `test_engine.py` |
| 7. 缺件等待 | 无件不占机位，到货后立即维修；等待分类不重复计时 | `test_engine.py` |
| 8. 补货去重 | 连续检查考虑在途量；待修需求仅补一次；到货仅一次 | `test_engine.py` |
| 9. 不变量 | 库存非负、机位容量、飞机状态互斥、库存流量守恒 | `test_engine.py` |
| 10. 截止与积分 | 处理截止同刻事件；保留任务/待修/维修/订单；积分至最后区间 | `test_engine.py` |
| 11. 确定性 | 相同配置种子的日志、指标相等；reset；分段推进；独立随机流 | `test_engine.py` |
| 12. 零值与非法输入 | 零任务/库存/故障率/机位合法；负数、非有限、非法类型、错误范围拒绝 | `test_config.py`、`test_engine.py` |
| 同刻边界 | 故障优先于任务结束；多机同刻坏而任务仅失败一次；完工/到货后可派机 | `test_engine.py` |
| 信息边界 | 观测不泄露未来任务、剩余寿命、随机数及事件队列；返回值可安全修改 | `test_engine.py` |
| 输出与命令行 | 实际配置、CSV、汇总 JSON、状态导出和图像；空任务表；CLI 错误提示 | `test_reporting.py` |

执行：`D:\conda_envs\sim-jev\python.exe -m unittest discover -s tests -v`。

随机验收另运行 default、stress 及两种配置的 seeds 0–9；实际结果、环境和输出文件核验记录见 `VALIDATION.md`。本项目无浏览器或 Web 接口，测试技能中的浏览器轮次不适用。
