# 阶段 2E-C1：冻结底座一次前向候选头 v0

本实验执行用户的 2026-11-10 2E-C1 prompt。历史 2E-B 数据只读，保留负结果。
范围是 336–504h 当前 offer cohort 已实现 DSR+RCR 的候选预筛；不包含长期价值、
720h 闭环、PPO、LoRA、双向注意力、远程推理或官方 Jev 请求。

## 数据与模型

训练/验证分别使用原 46/15 个有效环境，balanced 为 22/7，scarce 为 24/8。
训练/验证新 DES 为零。训练、选参不读原测试标签。所有旧公开状态参与业务去重。
原 ZIP、清单、model-seal、test-action-seal 与 A.json SHA 必须匹配用户指定字节。
每候选 32 个参考情景从原始分子/分母核算；512 次同索引 bootstrap 投票，精确并列平分，
0.02 均匀平滑。状态顺序为 split(train,validation)、state_id 字典序，随机种子 2026111007。

底座固定 Qwen/Qwen3.5-0.8B-Base，revision dc7cdfe2ee4154fa7e30f5b51ca41bfa40174e68。
原生 AutoModel 加载 checkpoint 后取 language_model；逐一核对全部文本张量。
不使用视觉、MTP、词表 logits 或 generate。离线加载，原生因果 SDPA，batch=1，无 padding。
实际 G0 决定 BF16 是否可用，并测试 FP32；不因新测试结果改变 dtype 或编码。

共同信息集是 residual_ranker.FEATURES 的 18 字段。乘 10000 后 numpy.rint 半偶舍入，
整数表示；缺失仅允许原 max_aircraft_hours 缺失产生的第 6 索引，符号 ?。
固定公共索引 10..15 写一次，其余 12 字段逐候选写入，不含 ID、任务名、seed、旧 Qwen 分数。
文本段分别 tokenize 并拼接，普通词表的 |candidate|、|decision| 标记末 token 位置直接登记。
上限 2048 tokens、16 候选；超长、缺必要字段均失败，不截断。

P 使用候选/末尾决策隐藏态、两个可训练 LN、无偏置 16 维投影和共享线性读出。
S 使用相同量化候选数值与缺失掩码（24维），公共字段/缺失与候选池均值（36维），
同样的 LN、16维投影和点积读出。容量不同须报告，不把 P-S 差异解读为全部架构因素的分离。
输出协议 local-qwen-pointer-v1；输出分布是有限仿真池的偏好，不是现实成功概率。

每训练环境原序加三个预登记唯一排列（seed 2026111008）。验证原序。
缓存键绑定官方资产、tokenizer、库与模型代码、dtype、实际 token IDs、标记位置、候选顺序。
四种排列先在环境内平均损失，再按固定 1/8 权重聚合独立环境；末批也用 1/8。
AdamW lr=.001、weight_decay=.01、clip=1；seed11 正式、29 稳定性；20 epochs、各120更新。
初始全局洗牌，每 epoch 全局重排环境组；保存 0/2/5/10/15/20 与 optimizer、RNG、游标。
选择规则为验证 K2/B4 最终遗憾、筛选损失、soft NLL、较早 epoch，依次字典序。
验证仅复用原在线情景索引0..3，不计新 DES/在线速度。保留初始存档以诊断训练增益。

## 新留出与计时

在模型与源码封存之后才构建 64 个 scarce 计划状态，默认 seeds9000..9063。
历史冲突预先以10000起最小未用整数替换。B2计划7000..7255及8000..8255保守保留。
在线/参考 seed 默认2026111013/2026111014，冲突预先各加100；生成 seed20261102。
前16计划槽分别倒序和一固定随机排列，seed2026111017；不换槽补样。

H32=K4/B8，H42=K4/B2，A8/S8/P8=K2/B4。五方法按计划 index mod5 循环移位。
全部通过 resolve_decision(DecisionRequest,CandidateHeadPolicySpec,HeadDecisionRuntime) 同一入口。
每方法重新建池、独立真实跑 DES，同状态同在线 CRN。P 每请求恰一次真实文本前向，无在线缓存。
空池无前向，单候选仍可评分但跳过 DES；主样本必须 M≥4。
连续计时从收到合法请求到动作校验与同步选择证据 fsync，包含建池、推理、DES、审计与账本I/O。
最终自报耗时的 action.json 文件写入在计时之后；选择证据已在计时内持久化。冷加载单列。
正式在线进程先用已见训练首状态做一次有账本的真实前向暖机，不新增DES或读取新状态。
所有在线动作与真实调用证据封存核 SHA 后才生成完整池参考：每候选32独立共同情景。
保留每个实际评估候选 index0 的完整物理样本，其他分支保留原业务标量与审计哈希。

## 分析、门与预算

主样本是未见、业务去重、M≥4且五方法/参考完整配对的环境，不补样。
环境 bootstrap5000（2026111015）；条件参考 MC bootstrap5000（2026111016），
环境内候选共享抽样索引，固定环境之间独立。两种区间分列，不把分支数当环境数。
P8改善 = q(P8动作)-q(对照动作)，与同池 max 相消。
扩大门要求 n≥48，P8对S8/A8/H42各改善≥.002、单侧环境95%下界>0，
且条件参考MC单侧95%下界>0；对H32遗憾增量单侧环境95%上界≤.005；
P50≤.8×H32、P95≤H32；合法性通过；至少24组换序、Top2集合一致率≥90%。
这些是预先固定的资源决策阈值；失败后不重训、换seed、升级模型或改门。

正式在线4096、参考32768、换序256，共研究DES≤37120；工程/回归≤1024。
轨迹≤64×336h。真实前向≤360且累计≤3600s，单次预留60s；未知尝试占额。
正式优化器更新≤480；工程smoke≤40。实际自回归、远程与官方Jev请求均为0。
每次计算先持久预约，结束登记；不重置额度，不重复正式研究以供审计。
完整历史回归曾需超过10000 DES，本轮按用户1024工程上限只跑关键行为回归并用干净源码复跑。

审计只读重算数据、选案、统计与成本。代码在项目，产物在G盘outputs独立任务目录；
外部模型与Conda不重打包。原工作区保持，不git add/commit/push。
